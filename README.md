# java-calculator-precourse

---

## 프로그램 소개

구분자와 양수가 문자열로 함께 입력되어 구분자로 양수를 구분하고 양수들의 합을 출력하는 문자열 덧셈 계산기입니다.

## 프로그램 사용 가이드

아래는 프로그램 사용 예시 입니다.(입력값은 예시입니다.) 기능에 대한 세부 사항은 구현 기능 목록을 통해서 확인하실 수 있습니다.

0. 프로그램을 시작하면 안내가 출력 됩니다.

```
덧셈할 문자열을 입력해 주세요.
```

1. 덧셈할 문자열을 입력합니다.(쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환하고 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수
   있다. 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.)

```
1,2:3
```

2. 입력을 완료하면 덧셈한 결과를 확인할 수 있습니다.

```
결과 : 6
```

### 실행 결과 예시

```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

## 기능 구현 목록

### 입력 기능

- [ ] 구분자와 양수로 구성된 문자열을 입력하는 기능
    - 잘못된 값을 입력한 경우 예외를 발생시킨다.

### 핵심 기능

- [x] 입력된 문자열을 쉼표(,) 또는 콜론(:) 구분자로 분리하는 기능
- [x] 입력된 문자열 앞부분에 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 분리하는 기능
    - 커스텀 구분자는 1글자 이상일 수 있다. ex) "//;.\n1;.2;.3" 일때 커스텀 구분자는 ";."
- [x] 분리된 문자열에서 숫자들을 정수로 변환하여 합을 계산하는 기능
- [ ] 숫자만 입력된 경우 해당 숫자를 반환하는 기능
- [ ] 빈 문자열을 입력할 경우 0을 반환하는 기능

### 출력 기능

- [ ] 문자열 입력 안내 메시지를 출력하는 기능
- [ ] 결과 안내 메시지와 덧셈한 결과 값을 출력하는 기능

### 예외 상황

사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

- [ ] 커스텀 구분자의 값이 입력되지 않은 경우
- [ ] 커스텀 구분자 외에 다른 문자가 구분자를 입력한 경우
- [ ] 커스텀 구분자를 입력하지 않고 기본 구분자 외 다른 구분자를 입력한 경우
- [ ] 계산 범위를 초과한 경우
- [ ] 구분자와 양수 사이에 공백이 입력된 경우
- [ ] 커스텀 구분자에 양수가 입력된 경우
- 양수가 아닌 수가 입력된 경우
    - [ ] 음수를 입력한 경우
    - [ ] 소수를 입력한 경우
    - [ ] 0을 입력한 경우
- 기타 잘못된 입력의 경우
    - [x] 공백문자(\n, \t, \r, (스페이스)) 또는 null을 입력한 경우
        - 빈 문자열("") 입력 시에는 0을 출력해야함
    - [x] 공백을 포함해서 입력한 경우

### 프로그램 흐름도

1. 덧셈할 문자열을 입력 받는다.
2. 입력된 문자열의 구분자로 구분자와 숫자로 구분한다.
3. 구분된 수들을 더한다.
4. 더한 값을 출력한다.
